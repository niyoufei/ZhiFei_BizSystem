# R6D1 产品交互与可访问性交付

## 优化范围

本节点只优化现有 FastAPI 首页壳，不改变 API 路径、请求方法、DTO、OpenAPI、评分逻辑
或存储语义。

- 提供“跳到主要内容”键盘入口和语义化 `main`；
- 增加固定工作流导航，直接到达认证、项目、资料、施组评分、对比、学习和输出区域；
- 增加中文语言、移动端 viewport、窄屏布局和横向表格滚动；
- 所有交互控件提供清晰 `focus-visible`，并尊重系统“减少动态效果”设置；
- 动态结果区使用 `role=status` 与 `aria-live=polite`，异步结果可被辅助技术感知；
- `safeClick` 操作进入 single-flight 状态，按钮显示忙碌标记并阻止重复提交，结束后按
  当前项目状态恢复控件；
- 所有主要按钮在移动端保持至少 44px 点击高度。

## 交互验收

1. 仅用键盘可从跳转链接进入主要内容，并沿工作流导航到各关键区域。
2. 同一异步按钮在请求完成前不会再次发起动作。
3. 成功、失败和加载结果进入礼貌播报区域，不抢夺当前焦点。
4. 760px 以下页面不产生表单横向溢出；宽表格仅在自身区域横向滚动。
5. 关闭动画偏好的用户不会持续看到旋转或平滑滚动。

## 安全边界

API key 仍只通过 `X-API-Key` 请求头发送，不进入 URL 或页面日志。single-flight 只约束
浏览器重复点击，不替代服务端幂等、事务或权限校验。页面未新增远程资源、第三方脚本或
遥测，不读取生产数据用于展示初始化。
